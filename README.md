# Chromatic

Ask in chat for a picture or a video. Chromatic makes it with your account and saves every shot from that chat on one canvas you can open on [chromaticlabs.co](https://www.chromaticlabs.co). The balance is the same wallet as the website.

## Install

After this plugin is listed, search **Chromatic** under Plugins in Cursor or Grok Bot, click Add, and sign in.

The server address is `https://mcp.chromaticlabs.co/mcp`.

## What it does

The agent can check your balance, list models, price a shot, upload a public image, and generate an image or video. Finished files land on a Chromatic canvas. The tools return a file URL, a job id, and a canvas id.
